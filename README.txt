StockMaster - Sistema de Controle de Estoque

Sistema web desenvolvido como projeto prático para a disciplina de Análise e Projeto de Sistemas. O StockMaster tem como objetivo automatizar o controle de inventário, gerenciar entradas e saídas de mercadorias, emitir alertas de estoque mínimo e assegurar a rastreabilidade por meio de logs de auditoria imutáveis.

## Tecnologias Utilizadas
* HTML5 & CSS3: Estrutura e estilização responsiva da interface (Single Page Application).
* JavaScript (Vanilla): Lógica de negócios, manipulação de estado e validação de regras.
* LocalStorage: Persistência local de dados no navegador.

##  Como Executar o Projeto
1. Clone o repositório para o seu computador ou faça o download dos arquivos.
2. Certifique-se de possuir um navegador web moderno (Chrome, Firefox, Edge ou Safari).
3. Dê um duplo clique no arquivo `index.html` ou abra-o diretamente utilizando o seu navegador de preferência.
